# Skills and a practical learning plan

## Start with a foundation

For engineering paths, practice programming, version control, APIs, data structures, and testing. For product paths, practice user interviews, clear requirements, prioritization, and basic data analysis. Every path benefits from communicating technical uncertainty clearly.

## Add AI-specific knowledge

Learn how model inputs and outputs behave, how to evaluate them, and how retrieval, tools, and structured outputs fit into applications. Understand privacy, security, latency, cost, and failure handling at a level appropriate to the role.

## Build evidence

Choose one realistic project and show the decisions behind it. Include a README, a working demo when practical, evaluation examples, known limitations, and what you would improve next. A thoughtful, scoped project is more useful than a list of buzzwords.

## Keep the plan flexible

Use job postings to prioritize learning. If a skill appears repeatedly in the roles you want, find a focused learning resource and apply it in a project.
