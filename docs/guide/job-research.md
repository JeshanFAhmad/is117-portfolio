# Researching job descriptions

Use a simple worksheet for each posting:

| Field | Notes |
| --- | --- |
| Company, title, link, date checked | |
| Team and product context | |
| Main responsibilities | |
| Required skills | |
| Preferred skills | |
| Customer-facing, research, product, or platform emphasis | |
| Experience level and location constraints | |
| Questions or unclear terms | |

After collecting several postings, group repeated responsibilities and skills. Distinguish requirements from preferences, and note when a title appears to describe different jobs at different employers. Job descriptions can change or close, so save the date checked and revisit your conclusions periodically.
