# AI Engineer

## What the role does

AI Engineer is a broad title for software-focused roles that build products or internal systems using machine learning models. Work may involve model APIs and LLM application patterns, traditional machine learning, or production infrastructure for model-powered features.

## Typical responsibilities to look for

- Build and maintain AI-powered application features
- Connect models to data, tools, and existing software systems
- Create evaluation and monitoring approaches for quality and reliability
- Improve latency, cost, security, and user experience
- Work with product, design, data, and infrastructure teams

## Common skill areas

Programming, software design, APIs, databases, testing, model evaluation, data literacy, and deployment fundamentals. Some openings require deeper ML or statistics; others emphasize full-stack product engineering.

## Portfolio idea

Build an application around a specific user need. Include tests or an evaluation set, explain how you handle incorrect outputs, and describe the system’s limitations.

## How to research postings

Separate requirements into software engineering, ML foundations, data, cloud, and product skills. Check whether “AI Engineer” means model research, application development, or platform work at that employer.
