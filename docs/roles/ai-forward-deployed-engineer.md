# AI Forward Deployed Engineer

## What the role does

An AI Forward Deployed Engineer (also called Forward Deployed AI Engineer or customer-facing AI Engineer at some companies) works close to users or customers to turn a real operational problem into a deployed AI solution. The role often spans discovery, prototyping, integration, and production handoff.

## Typical responsibilities to look for

- Map customer workflows and identify where AI could help
- Build prototypes using model APIs, retrieval, tools, and existing data
- Integrate the solution with customer systems and deployment constraints
- Evaluate quality with representative examples and user feedback
- Explain trade-offs to both technical and nontechnical partners

## Common skill areas

Software engineering, API integration, data handling, LLM application patterns, evaluation, debugging, communication, and comfort working through ambiguous requirements. The balance varies: some jobs are primarily engineering; others include substantial implementation consulting.

## Portfolio idea

Choose a well-scoped workflow, interview a few potential users, build a small AI-assisted prototype, and document evaluation cases, failure modes, privacy assumptions, and deployment considerations.

## How to research postings

Search for “forward deployed engineer” alongside “AI” and “LLM”. Record how much time the posting assigns to coding, customer work, travel, deployment, and product feedback. Compare the actual responsibilities across companies.
