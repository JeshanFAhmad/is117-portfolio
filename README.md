# AI Career Atlas

**Explore the roles shaping the growing AI industry.** This project researches new and evolving careers such as AI Forward Deployed Engineer, AI Engineer, AI Product Manager, and AI Safety & Evaluation specialist.

🌐 **Website:** https://jeshanfahmad.github.io/is1117-portfolio/

## What you’ll find

- Plain-language role profiles: what people do, where they work, and how roles differ
- Common skills, tools, and experience employers ask for
- Learning plans and project ideas for building evidence of those skills
- A research guide for comparing real job descriptions as titles evolve

## Browse the site

- [Role library](https://jeshanfahmad.github.io/is1117-portfolio/roles/)
- [Career guide](https://jeshanfahmad.github.io/is1117-portfolio/guide/)

## Run locally

```sh
npm install
npm run docs:dev
```

Build the static site with `npm run docs:build`. GitHub Actions publishes the generated site to GitHub Pages whenever changes are pushed to `main`.

## Research approach

AI job titles are inconsistent and change quickly. Treat titles as clues, compare responsibilities across postings, and note the date and source for every claim. The role pages are starting points for research, not guarantees about every employer’s definition.

## Contributing

Add a source-backed role or update an existing profile. Include source links and the date reviewed so readers can check how current the information is.
